# Тестирование веб-приложения: портал «Инструменты тестировщика»

## Задача / О проекте

Учебный мини-портал на HTML/CSS с тремя разделами (командная строка Windows, терминал macOS, Git). Моя роль: провести тестирование вёрстки — найти опечатки, некорректные ссылки и смысловые ошибки в описаниях команд, задокументировать дефекты и исправить их в коде.

## Что я делал

- Провёл ручное тестирование 4 HTML-страниц (`index.html`, `cmd.html`, `mac.html`, `git.html`): проверил текст, ссылки, структуру тегов и корректность технического содержания.
- Нашёл и задокументировал **27 дефектов**: опечатки («Windos» → «Windows», «расфшифровывается» → «расшифровывается»), битые ссылки (переход с `git.html` вёл на `mac.html` вместо главной), нарушения структуры HTML (незакрытые теги `</div>`, `</p>`, устаревший атрибут `align`), смысловые ошибки в описании команд (перепутаны `DIR`/`CD`, `DATE`/`TIME`, несуществующая команда `MAKEDIR`, неверные расшифровки `mv`/`mkdir`).
- Обнаружил критическую логическую ошибку: страница `git.html` называлась «Git», но фактически содержала описание команд терминала (не Git) — потребовалось переписать содержимое, добавив реальные команды Git (`git init`, `clone`, `add`, `commit`, `push`, `pull`, `status`, `branch`).
- Исправил все найденные дефекты в коде и проверил результат в браузере.
- Оформил список дефектов по каждому файлу отдельно в `defects.txt` для наглядной документации проделанной работы.

## Решение и артефакты

> Это доказательная база навыков — все артефакты приложены в этом кейсе.

- **Баг-репорт / список дефектов** (27 пунктов по 4 файлам с описанием «было → стало») — `bug_reports/defects.txt`
- **Исправленный исходный код** (HTML/CSS/JS-ресурсы) — `src/`
- **Скриншоты исправленных страниц** — `resources/`
- **Список дополнительных улучшений** (шаблон для необязательных доработок) — `docs/improvements.txt`

## Результаты

- Исправлено 27 дефектов на 4 страницах: 9 в `index.html`, 7 в `cmd.html`, 7 в `mac.html`, 4 (+ полная переработка контента) в `git.html`.
- Восстановлена логическая целостность портала: страница «Git» теперь действительно описывает команды Git, а не дублирует терминал macOS.
- Навигация между страницами исправлена (ссылка с `git.html` корректно ведёт на главную).

## Используемые инструменты

HTML, CSS, Git/GitHub (репозиторий проекта), браузер для визуальной проверки.
