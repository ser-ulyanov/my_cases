1. Описание проекта

Тестирование новой функциональности 'Личные события' на вкладке 'Расписание' портала преподавателя. Цель — убедиться, что функции создания, редактирования, удаления и отображения личных событий работают в соответствии с требованиями."

Ссылки на требования: материалы из вкладки “Курсовая по основам тестирования”

5. Используемые программные средства 


1. Система управления тест-кейсами Test IT Cloud
2. Браузер Microsoft Edge Версия 141.0.3537.57 (Официальная сборка) (64-разрядная версия)
3. Инструменты для API-тестирования
   - Postman - создание и выполнение API-запросов
   - Postman Runner - запуск коллекции тестов
   - Переменные окружения- базовый URL и токен авторизации
