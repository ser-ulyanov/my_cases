## Описание проекта

        

*Проект представляет собой тестирование веб-приложения - интернет-магазина книг «Читай Город».*

*Основная **цель приложения** - предоставить пользователям возможность удобного поиска, выбора и покупки книг онлайн. Тестирование направлено на проверку стабильности и корректности работы ключевых пользовательских сценариев, так как от их работоспособности напрямую зависит прибыль магазина и удовлетворенность клиентов.*

  

***Объект тестирования***

*В рамках данного этапа тестирования проверке подлежит следующий функционал:* 

·       ***Поиск товара:*** *Строка поиска, фильтры (по жанру, автору, цене), выдача результатов поиска.* 

·       ***Добавление товара в корзину:*** *Функция добавления с карточки товара и из списка поиска, изменение количества позиций, удаление из корзины.* 

·       ***Оформление заказа:*** *Форма ввода данных (контактная информация, адрес), выбор способа доставки и оплаты, отправка заказа.*

## Виды тестирования

В рамках проекта были проведены следующие виды тестирования:

- **Смоук-тестирование:** Для проверки стабильности основных пользовательских сценариев.
- **Функциональное тестирование:** Для проверки корректности работы всех заявленных функций.
- **API-тестирование:** Для проверки интеграции между клиентской частью и сервером, корректности обработки запросов и ответов.
- **Нефункциональное тестирование:**
  - **Тестирование производительности (нагрузочное):** Проверка времени загрузки страниц при разных скоростях интернета (3G).
  - **Тестирование стабильности (нагрузочное):** Проверка потребления памяти при длительной работе.
  - **Тестирование доступности (Accessibility):** Проверка соответствия контрастности текста стандартам WCAG.
  - **Кроссбраузерное тестирование:** Проверка работы в браузерах Chrome, Яндекс.Браузер, Microsoft Edge.

## Используемые программные средства

- **Браузеры:**
  - Яндекс.Браузер Версия 26.3.0.2166 (64-bit)
  - Google Chrome Версия: 146.0.7680.80 (официальная сборка) (64 бит)
  - Microsoft Edge Версия 146.0.3856.62 (Официальная сборка) (64-разрядная версия)

- **Инструмент для анализа производительности:** Google PageSpeed Insights
- **Инструмент для управления задачами/баг-трекинг:** Встроенная система в Test IT
- **Средства разработки/отладки:** DevTools (F12) для эмуляции сети, проверки консоли и производительности.
