# Финальный проект по ручному тестированию: интернет-магазин «Читай-Город»

## Задача / О проекте

Комплексное тестирование продакшн-версии реального интернет-магазина книг chitai-gorod.ru. Объект тестирования — три ключевых пользовательских сценария: поиск товара, добавление в корзину, оформление заказа. Моя роль: спланировать и провести полный цикл тестирования (функциональное, смоук, API, нефункциональное), задокументировать результаты и дать рекомендации по релизу.

## Что я делал

- Составил тест-план с декомпозицией функционала (поиск, корзина, оформление заказа), описанием окружения и используемых инструментов.
- Разработал тестовую документацию: 3 смоук-теста, функциональный чек-лист (14 пунктов: поиск, фильтры, сортировка, корзина, оформление заказа), нефункциональный чек-лист (15 пунктов: производительность, кроссбраузерность, доступность, память), 9 API-тест-кейсов.
- Провёл функциональное и смоук-тестирование через TestIT (7 тестов в тест-плане, 42.9% успешных).
- Собрал коллекцию в Postman из 9 запросов (4 позитивных / 5 негативных) и прогнал тест-ран — 6 успешно / 3 провалено.
- Провёл нефункциональное тестирование: анализ производительности через Google PageSpeed Insights, тест на утечки памяти (30 минут непрерывной работы), проверку контрастности по WCAG, кроссбраузерное тестирование (Chrome, Яндекс.Браузер, Edge).
- Нашёл и оформил 7 дефектов с приоритетом, серьёзностью и шагами воспроизведения.
- Составил итоговый отчёт со статистикой, рекомендациями по приоритету исправления и решением о готовности к релизу.

## Результаты

- Функциональные и смоук-тесты (TestIT): 7 тестов, 42.9% успешных (3), 57.1% провалено (4).
- API-тесты (Postman): 9 запросов, 6 успешно / 3 провалено (66.7%).
- Всего по чек-листам: 45 тестов, найдено **7 дефектов** (0 критических, 1 с высоким приоритетом).

**Найденные дефекты:**

| ID | Дефект | Приоритет | Серьёзность |
|---|---|---|---|
| CG-05 | API возвращает 200 OK вместо 406 Not Acceptable при некорректном заголовке Accept | High | Major |
| CG-03 | Загрузка главной страницы при медленном соединении (3G) > 3 секунд | Major | Medium |
| CG-02 | Контрастность текста и фона не соответствует WCAG для слабовидящих | Medium | Minor |
| CG-04 | Нельзя добавить сразу несколько единиц товара в корзину | Medium | Minor |
| CG-01 | Нет всплывающего уведомления при добавлении товара в корзину (веб) | Minor | Low |
| CG-06 | Нет уведомления о добавлении в корзину для неавторизованного пользователя | Low | Minor |
| CG-07 | Нет уведомления о добавлении в корзину для авторизованного пользователя | Low | Minor |

**Производительность (PageSpeed Insights):** производительность 74/100, доступность 69/100, рекомендации 73/100, SEO 100/100. Утечек памяти за 30 минут не обнаружено (+1.84 MB — в пределах нормы).

**Рекомендации по приоритету:** 1) исправить обработку заголовка Accept в API (High); 2) оптимизировать загрузку страницы — убрать неиспользуемый JS/CSS (Medium); 3) улучшить цветовой контраст по WCAG (Medium); 4) добавить уведомление о добавлении в корзину (Low); 5) добавить выбор количества товара перед добавлением (Low).

## Используемые инструменты

TestIT (тест-планы, тест-кейсы), Postman (API-тестирование), Google PageSpeed Insights (производительность и доступность), Chrome DevTools (эмуляция сети, память), Chrome / Яндекс.Браузер / Microsoft Edge (кроссбраузерное тестирование).
